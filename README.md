# ChatGPT Cooks

把實際冰箱食材整理成可以在手機上邊煮邊操作的料理流程。

目前首頁：**蝦・鮮蚵・櫛瓜檸檬奶油燉飯**。

## 使用

GitHub Pages / `index.html` 皆可直接開啟。頁面為單檔靜態 HTML，沒有套件或建置步驟。

目前針對手機下廚情境設計：

- 2 人 / 4 人份一鍵切換
- 依實際購買的「三好米 星川壽司米」調整流程
- 新鮮蒜頭版本
- 一次只顯示目前料理步驟，字體與操作按鈕放大
- 固定底部「上一步 / 完成這步」操作列
- 可展開完整食材與全部步驟並快速跳轉
- 部分步驟內建倒數計時與震動提示
- 支援 Screen Wake Lock 的瀏覽器可在料理時保持螢幕亮著
- 目前步驟與份量會保存在瀏覽器 localStorage
- iPhone / Android 安全區域與窄螢幕排版

## 本次食材

三好米星川壽司米、帶頭草蝦、鮮蚵、櫛瓜、洋蔥、新鮮蒜頭、史雲生極鮮清雞湯、無鹽奶油、稀釋檸檬汁；白酒為選配。

本版料理流程已調整為：星川壽司米不洗不泡、蝦先煎到剛熟並在最後短暫回鍋、鮮蚵在米還差約 3–4 分鐘時加入並煮至不透明。
