# ChatGPT Cooks

把實際冰箱食材整理成可以在手機上邊煮邊勾選的料理流程。

目前首頁：**蝦・鮮蚵・櫛瓜檸檬奶油燉飯**。

## 使用

直接開啟 `index.html` 即可。頁面為單檔靜態 HTML，沒有套件或建置步驟。

功能：

- 2 人 / 4 人份一鍵切換
- 壽司米 / Arborio・Carnaroli 時間提示切換
- 17 步料理流程與完成勾選
- 進度會保存在瀏覽器 localStorage
- 手機版排版
- 可列印

## 本次食材

草蝦、鮮蚵、櫛瓜、洋蔥、史雲生清雞湯、無鹽奶油、稀釋檸檬汁與米。

小磨坊香蒜粒可用來替代新鮮蒜頭；頁面採少量起始、短時間加熱並以熱高湯回潤的做法。
